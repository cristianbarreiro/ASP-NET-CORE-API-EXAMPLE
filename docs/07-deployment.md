# 07 — Configuración y deployment

## Objetivos
- Diferenciar Development, Staging y Production.
- Configurar logging y health checks.
- Empaquetar la API con Docker.
- Preparar PostgreSQL para un entorno persistente.

## Ejercicios
1. Agrega un endpoint `/health`.
2. Mueve configuración por ambiente a `appsettings.*.json` y variables de entorno.
3. Crea un Dockerfile multi-stage.
4. Agrega PostgreSQL con Docker Compose.
5. Publica la API y documenta variables necesarias.

## Criterio de finalización
Puedes ejecutar la API de forma reproducible fuera de tu IDE.
