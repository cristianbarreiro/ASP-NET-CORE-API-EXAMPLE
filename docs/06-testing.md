# 06 — Testing

## Objetivos
- Diferenciar pruebas unitarias e integración.
- Probar reglas del dominio sin infraestructura.
- Probar endpoints con `WebApplicationFactory`.

## Ejercicios
1. Ejecuta `dotnet test`.
2. Agrega pruebas para completar una tarea.
3. Crea un proyecto de IntegrationTests con `Microsoft.AspNetCore.Mvc.Testing`.
4. Prueba POST seguido de GET.
5. Verifica respuestas 400 y 404.

## Criterio de finalización
Puedes probar reglas de negocio y el pipeline HTTP sin depender de pruebas manuales.
